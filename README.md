🎨 **termix** — A lightweight Rust library for beautiful, colorful terminal output.

Make your CLI applications more expressive with simple ANSI styling, foreground and background colors, and easy-to-use macros.

✨ Features:
- 🌈 Foreground and background colors
- 🎨 RGB, HSL, and HSV color support
- 🖌️ Simple color macros
- 🔄 Nested color context management
- ⚡ Lightweight and easy to integrate
- 🦀 Built entirely with Rust
